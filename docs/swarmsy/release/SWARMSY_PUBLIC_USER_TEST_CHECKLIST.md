# SWARMSY Public User Test Checklist

Browser-only steps for a normal user:

1. Open the hosted SWARMSY URL.
2. Log in.
3. Create HIVE.
4. Load doctrine docs.
5. Start intake.
6. Memory lock.
7. Campaign calendar.
8. Proof review.

Normal users only use the hosted URL in a browser.
Developer/operator commands are not part of this checklist.
